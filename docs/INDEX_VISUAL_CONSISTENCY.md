## ✅ Checklist Rapide

### Avant de Commencer un Écran

- [ ] J'ai lu le [Guide de Démarrage Rapide](./QUICK_START_YY_COMPONENTS.md)
- [ ] J'ai importé `YYTheme` et les composants `YY`
- [ ] Je connais les règles strictes (pas de couleurs en dur)

### Pendant le Développement

- [ ] J'utilise `YYScreenContainer` comme conteneur
- [ ] J'utilise les composants `YY` (Button, Card, FormField, etc.)
- [ ] J'utilise `YYTheme` pour toutes les couleurs/styles
- [ ] Je teste régulièrement sur Web

### Avant de Valider

- [ ] J'ai testé sur Web
- [ ] J'ai testé sur iOS
- [ ] J'ai testé sur Android
- [ ] L'apparence est identique sur les 3 plateformes
- [ ] Aucune couleur en dur dans mon code
- [ ] Aucun `Platform.OS` pour le design
